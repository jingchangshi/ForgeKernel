# RMSNorm 40 轮优化计划（Ascend950PR / TileLang-Ascend）

状态：执行中。更新：2026-11-02。上承 `workplan.md`、`simdvf-dma-plan.md`、`simdvf-dma-review.md`。

## 0. 目标（可判定的定义）

逐 shape 达到：**点估计 speedup ≥ 1.0 且配对 bootstrap 95% 下界 ≥ 0.98**，其中 speedup = 厂商设备时长 / 候选设备时长，同一测量窗口内配对。

- prefill 8192×4096 bf16，decode 64×4096 bf16，eps=1e-6，fp32 统计，末尾一次 bf16 舍入。
- 两 shape 分别判定；禁止用几何平均掩盖任一 shape 失败。
- 证据不足（窗口不够、见证不可用）判 **RETEST**，不得判 PASS。

**当前起点（诚实）**：prefill ≈0.39x（SimtVF cw4，读数受争用影响）；decode 约 1.09x 但**多次独立验收均为 RETEST**，未认证。新路线 SimdVF+DMA 的 bf16 载入已实测正确，归约/写回/性能未验证。

## 1. 阶段与轮次

| 阶段 | 轮次 | 目标 | 出口门 |
|---|---|---|---|
| A 归约打通 | 1–6 | SimdVF 内跨 lane 归约到标量、bf16 写回、rstd 广播；单行 4096 正确 | 单行输出对 CPU float64 相对误差 ≤ 2^-7 |
| B 完整内核 | 7–12 | 多核(64)行映射 + DMA 流水；两 shape 正确 | 两 shape 全输入族精度通过 |
| C 计时与优化 | 13–18 | 同窗口配对计时；融合两遍、减指令 | 有可信配对数据，且优于 SimtVF 基线 |
| D 攻克差距 | 19–26 | 在线单遍、split-D、更大向量、UB 调优 | prefill ≥1.0 或明确记录不可达原因 |
| E 加固 | 27–32 | 保留集种子、极端输入、边界行 | 精度与鲁棒性全绿 |
| F 独立验收+闭环 | 33–38 | AgentGates 独立验收 + ForgeKernel KEEP/REVERT | 15+ 配对、多进程、见证充分 |
| G 终验归档 | 39–40 | 逐 shape 终验、证据归档 | 两 shape 均达标并归档 |

## 2. 每轮固定动作

1. 读当前证据与最近阻塞点；只攻击**最高未知**。
2. 用探针/最小内核验证，标注 [已实测]/[未验证]。
3. 通过门才前进；失败即回退并记录原因。
4. 每轮结束提交：代码/证据 + 一行结论。
5. 每 5 轮做一次诚实复评：是否偏离目标、是否该换路线。

## 3. 关键决策门

- **D1（第 6 轮）**：若 SimdVF 归约/写回无法在 6 轮内做到单行正确 → 回退 SimtVF 路线，转攻 DMA/融合/布局，不再纠缠微指令。
- **D2（第 12 轮）**：若完整内核正确但慢于 SimtVF cw4 → 放弃 SimdVF，保留 SimtVF 并转 D 阶段其它手段。
- **D3（第 26 轮）**：若 prefill 仍 <1.0 → 明确写出"当前手段不可达"的具体证据，转入 E/F 把已有最优如实验收，不虚报。
- **D4（第 38 轮）**：验收不足 → RETEST，延长而不放宽判据。

## 4. 风险与对策

1. **归约开销吃掉收益**：先在 A 阶段量归约指令占比；必要时用部分和 + 二次小归约。
2. **bf16 写回语义错**：一律先对 CPU float64 验，错即停。
3. **共享卡争用**：只做同窗口配对，不用跨 run 绝对时间；见证不足判 RETEST。
4. **UB 预算**：每个新内核按自身分配实测，不套用 262144 B 的单探针观测。
5. **agent 闭环不稳定**：两名成员已连续失败；闭环只作为 F 阶段的一个证据源，不作为唯一路径。

## 5. 现有后台 run 的处理

两个 ForgeKernel run（PyTorch 参考 run 与厂商参考 run）仍在 teacher 阶段。**第 1 轮内**检查其预算并收割或停止；若产出候选，作为 F 阶段 KEEP/REVERT 的输入，但不作为达标证据。

## 6. 停止条件

- 达成：两 shape 均 ≥1.0 且下界 ≥0.98，独立验收通过并归档。
- 不可达：D3 触发且证据充分 → 如实报告逐 shape 现状与差距，不标完成。
- 预算耗尽（40 轮）：如实汇总，未达标则不标完成。

## 7. 轮次细则

- R1：钉死 vcadd 归约链；测归约开销。
- R2：钉死 bf16 `vsts` 写回与 rstd 标量广播。
- R3：单行 4096 平方和 → 标量，对 float64 验。
- R4：单行完整 RMSNorm 原型，对 float64 验。
- R5：多行单核正确性；UB 实测。
- R6：决策 D1。
- R7–R12：多核映射、DMA 流水、两 shape 正确性，D2。
- R13–R18：配对计时框架、融合、指令精简。
- R19–R26：结构性手段（在线单遍/split-D/布局），D3。
- R27–R32：输入族与保留集加固。
- R33–R38：独立验收与闭环，D4。
- R39–R40：终验与归档。
